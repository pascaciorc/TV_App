# TV App

TV App is an Android coding challenge project that **consumes a REST API**, **loads multimedia content**, and displays a **Home screen with carousels**.  
The app is built using **Kotlin**, **Jetpack Compose**, and follows the **MVVM architecture pattern**.

---

## Features

- Fetch data from a REST API using **Retrofit** + **OkHttp**
- Display multimedia content in a modern **Compose UI**
- **Home screen** with dynamic carousels for different categories
- Asynchronous data loading with **Coroutines** and **Flow**
- Image loading and caching with **Glide**
- Seamless navigation using **Navigation Compose**
- Follows **MVVM architecture** and **Clean Code** principles
- Test UseCase with **JUnit**

---

## Tech Stack

| Layer | Technology |
|-------|-------------|
| **Language** | Kotlin |
| **UI** | Jetpack Compose |
| **Architecture** | MVVM |
| **Networking** | Retrofit + OkHttp |
| **Asynchronous Handling** | Kotlin Coroutines + Flow |
| **Navigation** | Navigation Compose |
| **Image Loading** | Glide |
| **Dependency Injection** | Hilt |
| **UI Test** | JUnit + Mockito |
